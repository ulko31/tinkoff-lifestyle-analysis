## Tinkoff Lifestyle Analysis

Аналитический кейс по исследованию поведения пользователей Tinkoff Lifestyle.

Цель проекта — понять, как меняются пользовательские расходы в зависимости от сезона, активности пользователя и уровня подписки, а также определить, как эти закономерности можно использовать для персонализации предложений и развития сервиса.

## Задача

Исследовать пользовательское поведение и ответить на вопросы:

- какие категории расходов являются наиболее популярными;
- меняется ли структура расходов в течение года;
- отличаются ли предпочтения пользователей с разными уровнями подписки;
- какие категории демонстрируют выраженную сезонность;
- как полученные закономерности можно использовать для развития продукта.

## Исследовательский вопрос

Основной исследовательский вопрос:

**Как связаны популярность различных категорий расходов, время года и уровень подписки пользователя?**

## Гипотеза

В рамках исследования была сформулирована гипотеза:

> некоторые категории становятся лидерами по популярности в определённые сезоны, а в течение остального года уступают другим видам расходов.

## Данные

Для анализа использовалась база пользовательских операций Tinkoff Lifestyle.

В исследовании учитывались:

- количество заказов;
- стоимость заказов;
- категория расходов;
- уровень подписки;
- месяц совершения операции.

Основные анализируемые категории:

- топливо;
- кино;
- путешествия;
- концерты;
- другое.

## Сегментация пользователей

Пользователи были разделены на три группы по количеству заказов.

```text
Стандартные пользователи: 0–2 заказа

Умеренно активные: 3–7 заказов

Высокоактивные: >7 заказов
```

Распределение пользователей:

- **0–2 заказа — 7 817 пользователей**
- **3–7 заказов — 1 834 пользователя**
- **более 7 заказов — 428 пользователей**

Это показывает, что большая часть аудитории относится к сегменту с относительно низкой частотой использования.

## Методология

Для исследования сравнивались наиболее популярные категории расходов у пользователей с различными уровнями подписки в разные месяцы года.

Использовались:

- сегментация пользователей;
- сравнение категорий;
- анализ средних значений;
- анализ сезонности;
- сравнение подписок;
- визуализация данных;
- обработка выбросов.

## Основные категории расходов

В общей структуре расходов анализировались:

- топливо;
- кино;
- путешествия;
- концерты;
- другие категории.

Сравнение позволило определить категории, которые занимают значительную долю пользовательской активности, а затем отдельно рассмотреть их динамику в течение года.

## Анализ подписок

Одной из задач было сравнение поведения пользователей с различными уровнями подписки.

При анализе учитывались:

- стоимость заказов;
- категории расходов;
- уровень подписки.

Это позволило увидеть различия не только между категориями, но и между пользовательскими сегментами.

## Обработка выбросов

В данных присутствовали отдельные значения, которые сильно отличались от основной выборки.

Для получения более устойчивой статистики была проведена обработка выбросов.

Сравнивались результаты:

```text
Исходные данные
vs.
Данные после обработки выбросов
```

Это особенно важно для категорий с высокой стоимостью отдельных покупок, где несколько крупных транзакций могут значительно искажать среднее значение.

## Сезонность

Один из ключевых результатов исследования — наличие выраженной сезонности в некоторых категориях.

### Кино

По анализу помесячной динамики категория «Кино» показывает повышенную популярность в зимний период.

Зимой показатели заметно выше, чем в течение большей части остального года.

Это подтверждает исходную гипотезу о том, что отдельные категории могут иметь сезонные пики.

### Путешествия

Категория «Путешествия» также демонстрирует выраженную сезонность.

Динамика отличается от кино и показывает периоды значительно более высокой пользовательской активности.

## Различия между подписками

Исследование также показало различия в структуре расходов пользователей в зависимости от уровня подписки.

Один из основных выводов:

- пользователи с Premium-подпиской чаще проявляют активность в категории **«Путешествия»**;
- пользователи без Tinkoff Premium сильнее проявляют интерес к категории **«Кино»**.

Таким образом, уровень подписки связан не только с общей активностью пользователя, но и с характером его потребления.

## Основные выводы

### 1. Пользователи существенно различаются по активности

Большинство пользователей совершают небольшое количество заказов.

Это означает, что для продукта важно отдельно работать с задачей увеличения frequency у малоактивного сегмента.

### 2. Категории имеют разную сезонность

Потребительские предпочтения меняются в течение года.

Например, категория «Кино» становится заметно более популярной в зимний период.

### 3. Уровень подписки связан с типом расходов

Premium-пользователи демонстрируют более высокий интерес к путешествиям, в то время как пользователи без Premium чаще выбирают кино.

### 4. Средние значения необходимо интерпретировать осторожно

Высокие значения отдельных транзакций могут сильно менять показатели категории.

Поэтому обработка выбросов является важной частью исследования.

## Product Insights

Полученные результаты можно использовать для развития персонализации Tinkoff Lifestyle.

### Сезонные предложения

Если известно, что интерес к определённой категории растёт в конкретный период, сервис может заранее предлагать:

- повышенный cashback;
- персональные предложения;
- акции партнёров;
- специальные подборки.

Например:

```text
Зима
→ предложения на кино

Периоды повышенного спроса на путешествия
→ туристические предложения и cashback
```

## Персонализация по подписке

Разные уровни подписки демонстрируют разные модели поведения.

Это позволяет формировать предложения отдельно для:

- пользователей без подписки;
- Premium-пользователей;
- других подписочных сегментов.

Например, Premium-аудитории можно активнее показывать travel-oriented предложения.

## Работа с малоактивной аудиторией

Поскольку большинство пользователей относится к сегменту с 0–2 заказами, отдельным продуктовым направлением может стать повышение активности этой аудитории.

Возможные механики:

- персональный cashback на наиболее релевантную категорию;
- welcome-offers;
- временные повышенные бонусы;
- recommendations based on similar users;
- специальные предложения после периода отсутствия активности.

## Ограничения исследования

У исследования есть несколько ограничений.

### Ограниченная возрастная группа

Доступные данные относятся только к пользователям в возрасте **14–18 лет**.

Поэтому результаты нельзя автоматически переносить на всю аудиторию Tinkoff Lifestyle.

### Отсутствие исторических данных

В датасете отсутствуют аналогичные данные за предыдущие годы.

Из-за этого невозможно определить, являются ли обнаруженные сезонные закономерности устойчивыми во времени.

Для подтверждения результатов потребовалось бы сравнение нескольких лет.
